AI SafeRoute V4

Complete System Specification & Feature Report

1. System Overview

Project Title: AI SafeRoute – Intelligent Disaster & Evacuation Management System
Current Version: V4.0 (MCFRI Engine Active)
System Role: A full-stack, AI-powered platform for real-time disaster monitoring, predictive flood simulation, and risk-aware navigation.

Core Architecture

  • Frontend: Vanilla Javascript (ES6+), HTML5 Semantic Structure, CSS3 (Glassmorphism), Leaflet.js (Mapping).
  • Backend: Node.js, Express.js (REST API), Prisma ORM.
  • Database: SQLite (Local) / PostgreSQL (Production Ready).
  • External Integrations: OSRM API (Real-Road Routing), CARTO Voyager (Map Tiles).

2. Predictive Simulation Engine (MCFRI)

The "brain" of the application, used to simulate catastrophic scenarios before they happen using the Modified Catchment Flood Risk Index (MCFRI).

  • Non-Linear Risk Calculus: Evaluates exponential factors including Rainfall, Soil Moisture, Drainage Quality, and Land Use Permeability to accurately model flash floods and ground saturation.
  • Flash Flood Rate Tracking (ΔR/Δt): Automatically monitors the velocity of incoming rain, distinguishing between slow accumulation and sudden, violent cloudbursts.
  • Fluid Spillover Logic: Simulates how floodwater moves across the landscape. Danger zones (Score > 140) automatically "spill" 10% of their risk score to any neighbors within a 2km radius.
  • Time Horizon Prediction: Projects the current risk intensity over a selectable 0–6 hour window, allowing responders to look into the future.
  • Adaptive AI Weights: A short-term memory system monitors the last 5 simulation states. If risk is escalating rapidly, it automatically adjusts its "Sensitivity Weights" to trigger earlier warnings.
  • Note: For intellectual property protection, the exact MCFRI formula has been securely abstracted from the public UI.

3. Intelligent Map & Navigation

The Live Risk Map is the primary operational interface for the user and emergency responders.

  • Real-Road Navigation (OSRM): Unlike simple "point-to-point" lines, the system calculates paths using actual streets and roads, providing accurate distance and duration estimates based on road geometry.
  • Risk-Aware Routing (The Fail-Safe Strategy): The routing engine actively evaluates the risk of every street segment:
    • Safe Route (Default): Strictly avoids all Warning and Danger zones.
    • Cautious Route (Fallback): If no purely safe path exists, it permits transit through "Warning" zones but completely avoids "Danger."
    • Emergency Route (Absolute Path): If every exit is blocked, it calculates the least-dangerous path through high-risk areas to reach safety.
  • Dual-Layer Visualization: The map renders two distinct indicators for each zone: an Inner Solid Circle representing the current physical risk, and a Dashed Outer Ring showing the predicted future risk footprint.

4. Emergency SOS Priority Intelligence

A high-fidelity triage system designed to coordinate rescue operations during mass-casualty events.

  • Priority Scoring Algorithm: SOS alerts are not handled simply "first-come, first-served." The backend scores every SOS request based on two critical factors:
    1. Localized Risk Score: Users physically trapped in Danger zones are pushed up the queue.
    2. Wait Time: The total elapsed time since the signal was activated.
  • Automated Triage Labels: Responders see requests automatically tagged as High (Red), Medium (Yellow), or Low (Green) priority.
  • Pulse-SOS Interface: The user-facing SOS button utilizes a rhythmic, high-visibility red pulse animation, designed for ease-of-use under extreme psychological stress.

5. Smart Shelter Management

Intelligent safe-haven coordination utilizing geographic proximity logic.

  • Smart Proximity Logic: Uses the Haversine Formula to constantly calculate the user's real-time distance to every available shelter.
  • The "Nearest" Badge: The UI automatically highlights and badges the absolute closest facility within the selected category.
  • Categorized Filtering: Users can filter for specific facility types:
    • Schools: For high-capacity, long-term stays.
    • Hospitals: For immediate medical emergencies.
    • Halls: For temporary refuge and assembly.
  • Infrastructure Protection Field: The Risk Engine recognizes shelters and applies a localized risk reduction (-40 points), simulating the advanced drainage and flood walls typical of designated safe havens.

6. Backend Infrastructure & Admin Console

A production-grade REST API backend built for rapid scaling and data persistence.

Core API Endpoints:
POST /api/risk — Offloads complex non-linear math to the server.
POST /api/sos — Registers emergency signals and runs priority triage.
GET /api/shelters — Fetches managed safe-facility data.
GET /api/sos — Real-time feed of all active rescue tickets for the Admin console.
  • Admin Dashboard: A real-time command center providing a feed of active rescue tickets, system statistics, and manual overrides for the simulation engine.
  • Data Safety: Utilizing Prisma ORM ensures that all SOS and shelter data is strictly typed and securely handled before touching the database.
