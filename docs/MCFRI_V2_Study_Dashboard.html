1. The MCFRI-V2 Master Equation

The Multi-Catchment Flood Risk Index Version 2 (MCFRI-V2) transforms multi-source meteorological, hydrologic, and topographic telemetry into a strictly bounded, non-linear risk score $S(t) \in [0, 200]$.

Master Bounded Formulation
$$S(t) = 200 \times \Big[ w_{RM} \cdot F_{RM} + w_{W} \cdot F_{W} + w_{T} \cdot F_{T} + w_{\Delta} \cdot F_{\Delta} \Big]$$
S
Bounded Composite Risk Score \(S(t) \in [0, 200]\)
A dimensionless continuous risk metric. Strictly bounded between 0 (Absolute Safety) and 200 (Catastrophic Flash Inundation).
200
Scale Multiplier (\(S_{\max}\))
Normalizes the unit sum of weights $\sum w_i = 1.0$ and unit factors $F_i \in [0, 1]$ to the human-interpretable 0–200 operational scale.
w
Normalized Component Weights (\(w_{RM} + w_W + w_T + w_\Delta = 1.0\))
Determines the proportional contribution of each environmental vulnerability channel. Evaluated with auto-normalization guards.
F
Four Non-Linear Sub-Component Risk Factors (\(F_i \in [0, 1]\))
Each factor isolates a distinct physical mechanism: rainfall saturation, water proximity/drainage, elevation/land permeability, and flash flood acceleration.

2. The Four Non-Linear Sub-Components

Rainfall-Moisture
Weight \(w_{RM} = 0.40\)
$$F_{RM} = r^\alpha \cdot \left(\frac{e^{\beta m} - 1}{e^\beta - 1}\right)$$

Models asymptotic rainfall saturation coupled exponentially with antecedent soil moisture. Dry soil absorbs rain; saturated soil produces rapid runoff.

  • Normalized Rainfall (\(r\)): R / (R + 150)
  • Soil Moisture (\(m\)): [0.0, 1.0]
  • Saturation Exponent (\(\alpha\)): 1.5
  • Moisture Exponent (\(\beta\)): 2.0
Water & Drainage
Weight \(w_W = 0.25\)
$$F_W = p^\gamma \cdot (1 - d)^\delta$$

Quantifies vulnerability from physical proximity to riverbanks/coastlines compounded by municipal drainage culvert deficits \((1 - d)\).

  • Water Proximity (\(p\)): raw (1-5) / 5
  • Drainage Quality (\(d\)): 0=poor, 1=opt
  • Proximity Exponent (\(\gamma\)): 2.0
  • Drainage Exponent (\(\delta\)): 1.5
Topography & Land-Use
Weight \(w_T = 0.20\)
$$F_T = (1 - h)^\epsilon \cdot (1 - l)$$

Quantifies vulnerability from low topographic elevation \((1 - h)\) (HAND) and urban concrete impermeability \((1 - l)\).

  • Topographic Safety (\(h\)): 0=basin, 1=crest
  • Surface Permeability (\(l\)): 0=paved, 1=forest
  • Elevation Exponent (\(\epsilon\)): 2.0
  • Permeability Term: (1 - l) linear
Flash Acceleration
Weight \(w_D = 0.15\)
$$F_\Delta = q^\eta$$

Half-wave rectified rate-of-change factor detecting cloudbursts. Rising rainfall spikes danger; steady or receding rain produces exactly zero.

  • Rain Acceleration (\(q\)): ΔR / (ΔR + 50)
  • Positive Rate (\(\Delta R\)): max(0, dR/dt)
  • Half-Sat Constant (\(Q_0\)): 50 mm/event
  • Acceleration Exponent (\(\eta\)): 1.2

4. Normalization Layer & Transfer Functions

A foundational innovation of MCFRI-V2 is its strict Normalization Pipeline. In V1, multiplying raw units (e.g. $300\text{mm}^{2.1} \times e^{2 \times 5}$) caused astronomical mathematical overflow ($> 10^{10}$) requiring artificial scaling divisors. In V2, every input is bounded in $[0, 1]$ before exponentiation:

1
Michaelis-Menten Rainfall Saturation: \(r = \frac{R}{R + R_0}\)
Maps unbounded rainfall $R \in [0, \infty)$ to $[0, 1)$. When $R = 0\text{mm} \implies r = 0$. When $R = 150\text{mm} (R_0) \implies r = 0.5$. When $R \to \infty \implies r \to 1.0$.
2
Rectified Acceleration Transfer: \(q = \frac{\max(0, \Delta R)}{\max(0, \Delta R) + Q_0}\)
Half-wave rectifies rainfall rates. If rain is receding or steady ($\Delta R \le 0$), $q = 0.0$. Cloudburst surges asymptotically approach $1.0$.
3
Unit Linear Clamping: \(x_{\text{norm}} = \max(0, \min(1, x))\)
Enforces strict boundary safety across soil moisture ($m$), drainage ($d$), permeability ($l$), and HAND topography ($h$).

6. Multi-Stage Secondary Processing Pipeline

After evaluating the raw core equation, the engine applies five downstream operational transformations:

1. Shelter Protection Field & Dampening
Zones within $800\text{m}$ of fortified shelters receive up to $-40\text{ pt}$ risk reduction, followed by a $0.80$ dampening multiplier: $$S_{\text{mitigated}} = (S_{\text{raw}} - \text{Bonus}) \times 0.80$$
2. Catchment Flood Spillover Propagation
Danger zones ($S > 140$) bleed $10\%$ of their risk score to adjacent catchments within $2000\text{m}$: $$\Delta S_{\text{spill}, j} = \sum_{i \ne j, S_i > 140} S_i \times 0.10 \times \left(1 - \frac{\text{dist}(i,j)}{2000\text{m}}\right)$$
3. Dynamic Footprint Radius Expansion
Visualizes expanding danger footprint on Leaflet maps: $$R_{\text{visual}} = R_{\text{base}} \times \left(1 + \frac{S_{\text{final}}}{200}\right)$$
4. Future Risk Trajectory Forecasting
Predicts risk evolution over a 1–6 hour horizon: $$S_{\text{future}} = \min\left(200, \; S_{\text{final}} + \left(\frac{R}{50}\right) t_h + 10 p t_h\right)$$
5. Adaptive FIFO Weight Memory Updates
Rolling 5-snapshot buffer adjusts rainfall-moisture sensitivity weights ($\pm 0.01$) during rapid upward or downward trend surges.

10. Implementation Reference Code

Use this standalone implementation script to reproduce the calculation in JavaScript or Node.js:

function computeMCFRIV2({ R = 200, m = 0.7, p = 0.8, d = 0.3, h = 0.2, l = 0.3, deltaR = 100, R0 = 150, Q0 = 50, alpha = 1.5, beta = 2.0, gamma = 2.0, delta = 1.5, epsilon = 2.0, eta = 1.2, wRM = 0.40, wW = 0.25, wT = 0.20, wD = 0.15 }) { // 1. Normalization Layer const r = R / (R + R0); const mNorm = Math.max(0, Math.min(1, m)); const pNorm = Math.max(0, Math.min(1, p)); const dNorm = Math.max(0, Math.min(1, d)); const hNorm = Math.max(0, Math.min(1, h)); const lNorm = Math.max(0, Math.min(1, l)); const q = Math.max(0, deltaR) / (Math.max(0, deltaR) + Q0); // 2. Non-Linear Components const FRM = Math.pow(r, alpha) * ((Math.exp(beta * mNorm) - 1) / (Math.exp(beta) - 1)); const FW = Math.pow(pNorm, gamma) * Math.pow(1 - dNorm, delta); const FT = Math.pow(1 - hNorm, epsilon) * (1 - lNorm); const FDelta = Math.pow(q, eta); // 3. Weighted Aggregation & Bounding [0, 200] const rawScore = 200 * (wRM * FRM + wW * FW + wT * FT + wD * FDelta); const finalScore = Math.max(0, Math.min(200, Math.round(rawScore))); return { finalScore, components: { FRM, FW, FT, FDelta } }; }
