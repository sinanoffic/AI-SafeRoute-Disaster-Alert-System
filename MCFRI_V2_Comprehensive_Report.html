1. Master Equation Formulation

The Multi-Catchment Flood Risk Index Version 2 (MCFRI-V2) transforms multi-source meteorological, hydrologic, and topographic telemetry into a strictly bounded, non-linear risk score $S(t) \in [0, 200]$. Unlike linear approximations where risk accumulates proportionally to rain volume, MCFRI-V2 models asymptotic saturation, moisture coupling, topographic attenuation, and rate-of-change cloudburst dynamics.

Master Bounded Equation
$$S(t) = 200 \times \Big[ w_{RM} \cdot F_{RM} + w_{W} \cdot F_{W} + w_{T} \cdot F_{T} + w_{\Delta} \cdot F_{\Delta} \Big]$$

2. Detailed Sub-Component Equations

Every sub-component isolates a distinct physical hazard mechanism and returns a normalized value in the unit interval $[0, 1]$:

1. Rainfall–Moisture Coupling ($F_{RM}$) $w_{RM} = 0.40$
$$F_{RM} = r^\alpha \cdot \left(\frac{e^{\beta m} - 1}{e^\beta - 1}\right)$$

Models asymptotic rainfall volume coupled exponentially with soil moisture. Dry soil absorbs rain; saturated soil produces catastrophic runoff.

• $r = \frac{R}{R + 150}$ (Michaelis-Menten)  |  • $\alpha = 1.5, \; \beta = 2.0$
2. Water & Drainage Vulnerability ($F_W$) $w_W = 0.25$
$$F_W = p^\gamma \cdot (1 - d)^\delta$$

Quantifies risk from proximity to riverbanks/coastlines compounded by municipal culvert and drainage inadequacy $(1 - d)$.

• $p = \text{raw}(1-5) \div 5$  |  • $d \in [0, 1]$  |  • $\gamma = 2.0, \; \delta = 1.5$
3. Topography & Land-Use ($F_T$) $w_T = 0.20$
$$F_T = (1 - h)^\epsilon \cdot (1 - l)$$

Structural risk from low topographic elevation $(1 - h)$ (HAND basin exposure) and urban concrete surface impermeability $(1 - l)$.

• $h = \frac{\text{elev}-1}{4} \in [0, 1]$  |  • $l \in [0, 1]$  |  • $\epsilon = 2.0$
4. Flash Flood Acceleration ($F_\Delta$) $w_D = 0.15$
$$F_\Delta = q^\eta$$

Half-wave rectified rate-of-change factor isolating sudden cloudburst surges. Steady or receding rainfall produces exactly zero.

• $q = \frac{\max(0, \Delta R)}{\max(0, \Delta R) + 50}$  |  • $\eta = 1.2$

function computeMCFRIV2({ R = 200, m = 0.7, p = 0.8, d = 0.3, h = 0.2, l = 0.3, deltaR = 100 }) { // 1. Normalization Layer [0, 1] const r = R / (R + 150); const mNorm = Math.max(0, Math.min(1, m)), pNorm = Math.max(0, Math.min(1, p)); const dNorm = Math.max(0, Math.min(1, d)), hNorm = Math.max(0, Math.min(1, h)), lNorm = Math.max(0, Math.min(1, l)); const q = Math.max(0, deltaR) / (Math.max(0, deltaR) + 50); // 2. Non-Linear Sub-Component Formulations const FRM = Math.pow(r, 1.5) * ((Math.exp(2.0 * mNorm) - 1) / (Math.exp(2.0) - 1)); const FW = Math.pow(pNorm, 2.0) * Math.pow(1 - dNorm, 1.5); const FT = Math.pow(1 - hNorm, 2.0) * (1 - lNorm); const FDelta = Math.pow(q, 1.2); // 3. Weighted Aggregation & Bounding [0, 200] const rawScore = 200 * (0.40 * FRM + 0.25 * FW + 0.20 * FT + 0.15 * FDelta); const finalScore = Math.max(0, Math.min(200, Math.round(rawScore))); return { finalScore, components: { FRM, FW, FT, FDelta } }; }
