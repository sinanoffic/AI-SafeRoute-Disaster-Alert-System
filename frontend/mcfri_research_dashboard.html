2. MCFRI-V2 Equation Architecture

Parameter Status: DEVELOPMENT DEFAULT — TO BE EMPIRICALLY ESTIMATED
The mathematical structure below is the defined MCFRI-V2 architecture. All numerical parameter values ($\alpha, \beta, \gamma, \delta, \epsilon, \eta, R_0, Q_0, w_i$) shown are development defaults only. They will be replaced with empirically estimated values during the calibration stage.
Master Bounded Equation
$$S(t) = 200 \times \Big[ w_{RM} \cdot F_{RM} + w_W \cdot F_W + w_T \cdot F_T + w_\Delta \cdot F_\Delta \Big]$$
$S(t) \in [0, 200]$  |  $\sum w_i = 1.0$  |  Each $F_i \in [0, 1]$
Rainfall–Moisture ($F_{RM}$) $w_{RM} = 0.40$
$F_{RM} = r^\alpha \cdot \left(\frac{e^{\beta m} - 1}{e^\beta - 1}\right)$

Asymptotic rainfall volume coupled exponentially with antecedent soil moisture.

$r = R / (R + R_0)$  |  $\alpha = 1.5$, $\beta = 2.0$ DEV DEFAULT

Water / Drainage ($F_W$) $w_W = 0.25$
$F_W = p^\gamma \cdot (1 - d)^\delta$

Water proximity compounded by drainage / retention deficit.

$\gamma = 2.0$, $\delta = 1.5$ DEV DEFAULT

Topography / Land Surface ($F_T$) $w_T = 0.20$
$F_T = (1 - h)^\epsilon \cdot (1 - l)$

Topographic basin exposure (HAND) and ground impermeability.

$\epsilon = 2.0$ DEV DEFAULT

Rainfall Acceleration ($F_\Delta$) $w_D = 0.15$
$F_\Delta = q^\eta$

Half-wave rectified cloudburst surge rate-of-change factor.

$q = \max(0, \Delta R) / (\max(0, \Delta R) + Q_0)$  |  $\eta = 1.2$ DEV DEFAULT

5. Master Analysis Grid

250 m
Common Analysis Grid Resolution

The flood-observation target (Global Flood Database v1) is available at 250 m. Therefore, the initial MCFRI-V2 validation dataset uses a 250 m common analysis grid. All predictor variables are spatially collocated to this grid.

Important: Spatial Resolution Warning
Resampling a coarse environmental product (e.g., IMERG at ~10 km, ERA5-Land at ~9 km) to 250 m does NOT increase its native spatial resolution. The resampled values are spatially smooth — this is spatial collocation, not resolution enhancement. The 250 m grid is chosen to match the target variable, not to imply fine-scale predictor detail.
MERIT Hydro Resolution Note
MERIT Hydro's native resolution is ~90 m (3 arc-second). It may remain at 90 m internally during preprocessing, but the final aligned analysis dataset is 250 m. Do NOT use a 90 m master analysis grid for the validation dataset.

9. AI SafeRoute Operational Layer

Operational Features ≠ Scientific Calibration
The features listed below are downstream application features of the AI SafeRoute disaster management platform. They consume the MCFRI-V2 score output but are NOT part of the initial core MCFRI scientific calibration or validation. They remain fully functional with the current development-default parameters.
Interactive Risk Map

Leaflet-based geospatial visualization with color-coded risk zones, dynamic radii, and layer controls.

Shelter Logic

Inverse-distance shelter protection bonus with configurable radius (800 m) and dampening (0.80).

Route Guidance

Risk-aware evacuation routing that avoids danger zones and prioritizes safe corridors.

Flood Spillover

Danger zones propagate 10% excess risk to adjacent zones within 2000 m radius.

Risk Forecasting

1–6 hour future trajectory projection based on current conditions and rainfall rate.

Alert System & SOS

Automated emergency notifications and SOS triage prioritization based on risk tier.

10. Mathematical / Software Integrity Tests

These Are NOT Empirical Flood-Model Validation Tests
The tests below verify engine mechanics, mathematical consistency, boundary clamping, and numerical stability. A test showing that scores remain bounded, weights sum to 1, no NaN values occur, or that falling rain produces $F_\Delta = 0$ is a software/mathematical integrity test — NOT empirical flood-model validation. Empirical validation requires calibrated parameters fitted against real-world observational flood datasets, which has not yet been performed.

11. MCFRI-V2 Research Roadmap

The complete research trajectory from data verification through publication. The current active stage is highlighted.

  • 1 Data source verification — Identify and verify availability of all satellite and reanalysis products Done
  • 2 One-event extraction — Extract and align all variables for a single historical flood event as proof-of-concept Active
  • 3 30-event MVP dataset — Build minimum viable dataset across diverse geographies and flood types
  • 4 Data quality control — Outlier detection, missing-value handling, and cross-source consistency checks
  • 5 Dataset freeze — Lock the master calibration/validation dataset with version control and provenance
  • 6 Parameter calibration — Optimize exponents, weights, and scaling constants against observed flood outcomes
  • 7 Spatial/event-block validation — Hold-out validation using spatial and temporal cross-validation strategies
  • 8 Baseline comparison — Compare MCFRI-V2 against null models, logistic regression, and existing flood indices
  • 9 Ablation analysis — Systematically remove components to quantify each factor's contribution
  • 10 Sensitivity analysis — Characterize model response to parameter perturbations and input uncertainty
  • 11 Threshold estimation — Derive empirically grounded Safe/Warning/Danger boundaries from ROC analysis
  • 12 Final paper — Peer-reviewed publication documenting methodology, results, and limitations
  • 13 Zenodo publication — Archival deposit of dataset, code, and reproducibility artifacts with DOI
